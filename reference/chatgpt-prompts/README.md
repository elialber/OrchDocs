# Prompts originais (ChatGPT)

Esta pasta guarda os prompts originais usados no ChatGPT, que servem de insumo para os Stages do OrchDocs.

Conteúdo esperado (colado pelo autor, sem edição):

- `00` a `12`
- `03A`, `03B`, `03C`
- `06A`
- transição para produção

Regras:

- Os arquivos são colados como estão; não reescreva nem complete.
- São referência, não fonte da verdade (ver hierarquia em `CLAUDE.md`).
- Enquanto um prompt não estiver aqui, trate o conteúdo dele como desconhecido.
